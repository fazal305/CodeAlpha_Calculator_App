# CodeAlpha Image Gallery

A polished responsive image gallery built with HTML, CSS, and vanilla JavaScript for the CodeAlpha Frontend Development Internship.

The gallery focuses on a smooth portfolio-style browsing experience with category filtering, live search, masonry layout switching, and a keyboard-friendly lightbox.

## Live Demo

https://fazal305.github.io/CodeAlpha_ImageGallery/

## Repository

https://github.com/fazal305/CodeAlpha_ImageGallery

## Features

- Responsive image grid for desktop, tablet, and mobile screens
- Category filters for nature, city, architecture, abstract, and people
- Live search by image title, category, or credit
- Full-screen lightbox with image details
- Previous and next navigation inside the lightbox
- Keyboard support for Left Arrow, Right Arrow, and Escape
- Masonry view toggle
- Browser fullscreen toggle
- Lazy-loaded local images
- Empty state for searches with no results
- Clean neon-inspired visual design without framework dependencies

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Fullscreen API

## What I Practiced

## Run Locally

1. Clone the repository.
2. Keep images inside `assets/images`.
3. Open `index.html` in a browser.

No build step or package installation is required.

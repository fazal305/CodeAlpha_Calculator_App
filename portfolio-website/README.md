# CodeAlpha Portfolio Website

A modern dark cyberpunk portfolio website built with HTML5, CSS3, JavaScript, and Bootstrap 5.

## Live Links

- GitHub Repository: https://github.com/fazal305/CodeAlpha_Portfolio_Website
- Live Demo: https://fazal305.github.io/CodeAlpha_Portfolio_Website/

## Overview

This portfolio website presents my frontend development skills, selected projects, resume, and contact information in a polished single-page layout.

It was built as part of the CodeAlpha Frontend Development Internship and later polished under the Fazal Labs portfolio ecosystem.

- Responsive portfolio layout

- About section

  Getting Started

Clone the repository:

git clone https://github.com/fazal305/CodeAlpha_Portfolio_Website.git

Open the folder:

cd CodeAlpha_Portfolio_Website

Open index.html in your browser.

No build tools or installation required.

Architecture Notes

The project is structured as a simple static frontend website.

index.html contains the portfolio sections.
styles.css handles the custom cyberpunk UI.
script.js handles reveal animations, active nav links, mobile menu closing, and demo form behavior.
assets/ stores the profile image and resume file.
